# batjorge.com Mandelbulber settings

Mandelbulber 2 settings files by Jorge (batjorge, https://fractal.batjorge.com), included with his permission. Kyma's *batjorge.com · Mandelbulber scenes* presets are imported from these files.

| File | Formula | In Kyma |
|---|---|---|
| voyager.fract | Amazing IFS | Voyager |
| cuentos.fract | Amazing IFS | Cuentos |
| una-de-setas.fract | Amazing Surf Mod 1 | Una de Setas |
| amrand.fract | Amazing IFS | Amrand |
| rusticalia-hybrid.fract | Mandelbox + Amazing IFS hybrid | not importable (kept as a test that hybrids are rejected) |

The other 43 files in the set use formulas outside the Amazing Surf family (Mandelbox, Kleinians, Koch, Mandalay, DIFS…) or are Mandelbulb 3D files, so they are not included.
